AI Report Bridge is a personal tool that automatically transfers selected research reports from its owner's local computer to the owner's own Google Drive for backup and review.

How it works

The local application uses rclone and Google OAuth. It uploads report files, checks file listings and downloads uploaded files to verify their contents. Google access is limited to the drive.file permission.

About this website

This is an informational website. It does not sign visitors in to Google, accept report uploads, process trades or offer investment services. The application is a personal, noncommercial tool, not a Google service.
